Classes instead of tags!

In our prior examples, we showed how you could use css to describe the style of tags. In this page, we demonstrate how to define style by classes instead.

This paragraph has a black background because it has the 'black-background' class, which I defined on line 6.

This paragraph has red text because it has the 'red-text' class from line 9.

This paragraph is both! Tags can have multiple classes added to them! Notice that both classes interact with the text color, which is why I used the "!important" command on line 11, to make sure it took precedence over line 8.
