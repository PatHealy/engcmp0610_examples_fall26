Containers!

This page has one big "container" div around it. That is the typical framing object in a bootstrap page.

Rows

We tend to break up containers into rows!

Rows are a default way to break up content vertically

Columns

Inside rows, we can place columns. Bootstrap breaks up the page into 12 columns.

You can use columns without specifying the size of the column, which will break the row into equally spaced column chunks.
Or you can specify the size of a column explicitly! This middle column is 10 units wide, meaning the two side columns in its same row will default to 1 unit.

Rows and columns work well with other content

Here we see an interesting way of formatting text next to an image. The image is in a size 4 column and this text is in a size 6 column, meaning both of the remaining two side columns become 1 unit each. The image itself resizes to fit its container thanks to the "img-fluid" tag.
